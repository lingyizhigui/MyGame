# MyGame

一个用 **C++20** 和 **raylib** 制作的小游戏学习仓库。<br>
A collection of small games made while I am learning **C++20** and **raylib**.

> 这是一个仍在开发中的个人学习项目（WIP），主要用于和朋友分享进度、交流代码和记录学习过程。

## 目前包含什么？

| 项目 | 状态 | 简介 |
| --- | --- | --- |
| `BrickBreaker` | 可玩 | 打砖块小游戏 |
| `VampireSurvivor` | 开发中 | 类《Vampire Survivors》的练习原型 |

## 如何运行 / Build and run

Releases中有自解压文件，可以直接游玩。 

如果你想自行构建或修改：

开发环境：Windows、Visual Studio 2022、MSVC v143、C++20。

1. 使用 Visual Studio 2022 打开 [MyGame.sln](MyGame.sln)。
2. 选择 `x64` 和 `Debug`（或 `Release`）配置。
3. 将想玩的项目设为“启动项目”，然后按 `F5` 构建并运行。
